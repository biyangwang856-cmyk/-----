# 能力与验证范围

交付目标是数据管线独立后端。自然语言模板白模、上传白模、H3渲染、预览下载、源语义/GT导出及任务权限/预算/恢复都保留。

独立代码没有原数据引擎的转换、清洗、外部数据集导入、构建发布、训练划分与评测模块，也没有相关依赖。隔离测试显式禁用这些依赖检查服务健康与OpenAPI，验证记录见本包validation.xml。

此前已完成：固定5秒Franka抓放；完整13.8秒用户上传到H3；双方块叠放带绿色干扰物的真实源仿真及一次H3。叠放为实验生成器，不在自然语言入口中承诺已支持任意叠放。

此次独立包重跑接口、媒体、任务防重、凭据、时长和恢复检查，并另跑真实物理专项；没有为打包再次付费调用H3。测试H3替身不算真实模型生成。

正式服务器与网页登录/网关没有部署联调；Linux/Docker需在目标环境再验证。Windows conda-forge PyBullet3.25与Linux PyPI3.2.7不同。源状态中的接触为24Hz边界采样，不能覆盖所有240Hz短暂接触。

当前模型仍可能改变构图、背景、动作时间或几何。源语义/GT不自动等于H3输出GT，训练级保真认证尚未完成。本包包含用户要求的密钥文件，只能私下部署后端，不能下发网页或公开上传。
