# 前端接入准则与接口流程

## 一、前端所需配置

API base URL 是后端部署地址，project默认为pipeline，Bearer令牌来自对应后端的配置。/docs与/openapi.json可查询；本包docs/openapi.json供接口工具导入。Python客户端Client与浏览器SyntheticClient都只负责请求，不在浏览器执行PyBullet。

部署本机时 base URL=http://127.0.0.1:8018；跨电脑时要由部署者设置可访问地址和绑定host，不能把localhost发给另一台电脑当作远程地址。浏览器跨源由 WHITE_RENDER_CORS_ORIGINS 列出实际前端域名。建议正式平台通过同源网关认证，不把服务长期令牌写死在公开网页。

所有业务路径以 /api/projects/{project} 开头，Authorization: Bearer <本后端平台令牌>。MiniMax Key只放后端；它和平台令牌不可互换。

## 二、上传白模 → 渲染

1. GET /synthetic/capabilities 检查启用能力。
2. POST /uploads，multipart字段file，取upload_id。
3. POST /synthetic/assets，{"upload_id":"...","description":"用户白模"}，取asset_id。
4. POST /synthetic/preflight，{"source_asset_id":"...","appearance_description":"真实浅橡木桌面、工业聚合物机械臂、柔和光照，保持源动作"}，不收费。
5. POST /synthetic/quotes，传相同source_asset_id和外观文字；可选duration_seconds。展示输入时长、请求输出时长和报价，取得用户确认。
6. POST /synthetic/jobs，Idempotency-Key请求头必须为此次点击保存的唯一键：

```json
{"mode":"uploaded_video_render","source_asset_id":"asset_id","render":{"quote_id":"报价ID","appearance_description":"和报价完全相同的外观描述","duration_seconds":14,"max_cost_minor_units":1500,"currency":"CNY","model":"MiniMax-H3","resolution":"768P","variants":1,"automatic_paid_retries":false}}
```

duration_seconds可省略采用报价值，明确填写必须与报价相同。max_cost_minor_units是分人民币，不要每种视频都写500。网络重试复用同一键与同一请求体，不能每次重试都换键。

7. GET /jobs/{job_id} 每2–5秒查询。queued/running继续，succeeded读取result.render_asset_id；失败展示error。phase只表示阶段，不编造百分比。
8. GET /synthetic/assets/{id}与/quality读取文件清单、源关系和质量。

输入MP4为2–15秒、H.264/HEVC、1–60 FPS固定帧率、45MB内，宽高256–1920、总像素不超过2,073,600、宽高比0.4–2.5。低于23.976FPS保留原件后前帧保持转24FPS，不截断、不加速；preprocessing.json保存映射，original.mp4保留原件，white_model.mp4为模型参考。H3输出支持4–15整数秒，默认向上取整参考片时长且至少4秒。

## 三、文字 → 白模 → 可选渲染

POST /synthetic/specs，{"description":"Franka 把红色方块抓起并放到桌面右侧，固定相机，5秒","appearance_description":"真实木纹和侧光"}。

只有status=ready才提交，网页展示parsed_spec和defaults；needs_input需补充，unsupported不执行。此版本为受限模板规则解析，不声称任意任务自动生成。

只生成白模：POST /synthetic/jobs，{"mode":"scene_only","spec_id":"...","spec_revision":1}，带幂等键；完成取result.source_asset_id，独立预览下载，不需要H3 Key。

直接渲染：以spec_id/spec_revision请求报价，提交mode=scene_and_render并附render。源物理任务成功后才提交付费请求，H3失败仍保留源白模。

如用户先预览满意白模，用其source_asset_id走uploaded_video_render可复用而不重复仿真。

## 四、播放、下载与源语义/GT

带鉴权GET /synthetic/assets/{id}/files/{filename}支持Range/206；filename来自清单，不允许任意磁盘路径。H3通常为rendered.mp4，白模为media/white_model.mp4。

video.src无法自行加Bearer，优先用平台同源代理或POST /synthetic/assets/{id}/media-link，{"filename":"rendered.mp4","expires_seconds":300}，返回相对链接加API根地址供播放器使用。链接到期重新申请，不写入公开日志。

源导出：POST /synthetic/exports，{"asset_id":"...","kind":"semantic_gt","purpose":"research"}，带幂等键。完成取export_asset_id下载bundle.zip。kind也可available或media。semantic_gt只适用于真实仿真源；普通MP4和H3输出没有真实动作/深度/接触GT。本包保留白模的语义/GT导出，它是源生成产物，不包含LeRobot转换或清洗功能。

## 五、费用、取消与恢复

报价绑定源哈希、外观及输出时长，30分钟有效，每份报价只绑定一个任务。预算是本地估算门槛，不是供应商实际账单强制上限。实际账单未知返回null。启动API或只上传、预检查不发收费请求。

后端先保存意图再POST一次H3，保存task_id。submission_unknown禁止盲目重发；由render_operator核对上游账号、输入与时间后POST /synthetic/jobs/{id}/reconcile，传task_id和note。POST /jobs/{id}/retry只安全恢复查询/下载或未开始收费的阶段，已失败生成需新的明确授权，不自动再付费。

POST /jobs/{id}/cancel只取消本地，不保证上游取消或退款。H3余额不足/授权错误要展示原任务error，不能自动换key重复提交。

## 六、上线与数据用途准则

当前为同机队列：API和worker共享本机持久数据目录。前端同学运行worker则用她的CPU；接远程API则用远程worker计算。正式网页仍需实际完成网关身份、项目隔离、CORS、播放器拖动、链接过期、重启恢复和文件下载验收。

任务succeeded只证明流程完成，不能等同保真通过。源状态、渲染RGB、质量报告分开，时间fail与几何/接触unknown按实际返回；当前training_eligible=false。漂亮视频不能自动当机器人监督训练数据。
