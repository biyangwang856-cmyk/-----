# 运行位置、安装与使用

## 运行究竟发生在哪里

网页只提交文字、视频和外观要求。API 保存任务，worker 执行仿真或调用 H3。白模使用 worker 所在机器的 CPU 与文件存储；H3 真正的视频生成在 MiniMax 云端。API 请求从部署机器联网发出，结果再下载回部署机器。

| 部署方式 | 白模在哪里生成 | 文件在哪里保存 |
|---|---|---|
| 同学在她电脑启动 API 和 worker | 她的电脑 | 她配置的数据目录 |
| 你的电脑启动 API 和 worker，网页访问你的后端 | 你的电脑 | 你的数据目录 |
| 后续服务器部署 API 和 worker | 服务器 | 服务器持久数据目录 |

仅双击前端网页不会启动你的电脑上的程序。她安装本包也不会自动连接你的电脑。若要你电脑承担计算，需要你电脑持续开机运行后端，并配好可达地址、端口、鉴权和域名。不能直接把她的 localhost 指向你的电脑。

当前独立 SQLite 队列要求 API 与 worker 在同机、同一个本地数据目录；不把队列文件放 NFS 或让两台电脑共享读取。同一服务可以启动多个本机 worker，但不要让其它任务抢占所需资源。

## Windows 本机（无 GPU）

安装 Python 3.12 与项目依赖。PyBullet 在 Windows 的 PyPI 源码包可能需要编译器，推荐 conda-forge 的二进制环境：

```powershell
conda create -n white-render --override-channels -c conda-forge python=3.12 pybullet=3.25 pip -y
conda activate white-render
# cd 到本交付包根目录
python -m pip install -e '.[dev]'
```

在两个终端中激活同一环境，分别执行：

```powershell
# 终端一
.\start.ps1 -Mode api
# 终端二
.\start.ps1 -Mode worker
```

端口默认为8018，项目名pipeline，数据保存在解压目录下work。脚本自动创建平台令牌 work/local-auth.private.json，并读取本包 private/minimaxapi.docx。此平台令牌用于浏览器调用本后端，不是 MiniMax Key。

可用 -Python 指定完整 python.exe，-DataRoot 指定其它本地数据目录（API和worker必须一致），API可用-Port改端口。/healthz 为服务健康检查，/docs 为接口调试页。若 PowerShell 策略不允许运行脚本，可直接设置 WHITE_RENDER_ROOT、WHITE_RENDER_AUTH_JSON、MINIMAX_API_KEY_FILE 后用下面命令启动：

```powershell
# WHITE_RENDER_AUTH_JSON 为 JSON：令牌 -> {project,roles} 映射
python -m white_render_backend.cli serve --host 127.0.0.1 --port 8018
# 第二个同环境、同变量终端
python -m white_render_backend.cli worker
```

## Linux / Docker

Linux Python3.12可安装 `pip install -e '.[simulation]'`。Windows conda PyBullet3.25与Linux PyPI3.2.7版本不同，目标环境需要重跑物理专项。

Docker已带compose.yaml与.env：`docker compose up --build -d`，检查 `docker compose logs -f worker`。密钥文档只读挂载至/run/private；API与worker使用同一work卷。请将.env中的CORS域名改成真实网页地址。Docker文件已提供，尚未在目标服务器实际验收。

密钥配置只供后端。换文档或环境配置后重启 API/worker。没有H3 Key仍可生成白模；Key能读取不代表余额够用。

## 白模与叠放实验

网页自然语言入口首版为固定5秒Franka单方块抓放。完整双方块叠放及绿色干扰物实验生成器随源码提供，可在已安装PyBullet的环境运行：

```powershell
python -c "from pathlib import Path; from white_render_backend.stacking import generate_scene; print(generate_scene(Path('work/stack_example'), {})['validation'])"
```

输出目录必须为空。仿真成功后把其 media/white_model.mp4 按上传路线送去 H3；这不会自动收费生成。叠放实验尚未注册成通用自然语言模板，不支持通过文字任意创建其它任务。

## 停止和测试

终端 Ctrl+C 或 docker compose stop；本地停止不等于上游已退款。普通pytest使用模拟H3响应，不产生费用，真实仿真需要PyBullet。本包没有自动发收费生成的启动动作；收费只发生在接受报价后创建渲染任务并由worker执行。
